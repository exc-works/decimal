# ملاحظات الإصدار v0.8.0

[جميع اللغات](https://github.com/exc-works/decimal/blob/v0.8.0/docs/releases/v0.8.0.md#languages)

يحدد v0.8.0 عقدًا عدديًا واضحًا، ويصحح تقريب العمليات الحسابية والدوال المتسامية،
ويحافظ على الحالة عند فشل فك الترميز، ويقلل تخصيص الذاكرة في العمليات الشائعة.
توجد تغييرات سلوكية مقارنةً بـ v0.7.0؛ اقرأ دليل الترقية قبل تحديث التطبيقات الحالية.

## تنبيهات الترقية

| المجال | التغيير والإجراء |
| --- | --- |
| المقياس الافتراضي للنتائج الرياضية | تتغير Sqrt وApproxRoot وLn وLog10 وExp من `max(input scale,30)` إلى `max(input scale,20)`. وتتغير Log2 من مقياس الإدخال إلى الحد الأدنى نفسه، أي 20 منزلة عشرية. استخدم WithPrec لتحديد المتطلبات صراحةً. |
| الأسس الصحيحة السالبة | يحل HalfEven محل RoundUp عند مقياس الإدخال: تصبح `3.00^-1` مساويةً لـ `0.33`، وتصبح `New(2).Power(-1)` مساويةً لـ `0`. اضبط المقياس المطلوب قبل حساب القوة. |
| فشل الحساب | تبلغ الجذور واللوغاريتمات وExp عن `ErrNoConvergence` عندما يتعذر إثبات صحة التقريب ضمن ميزانية الحساب. تحقق من الأخطاء؛ تحتفظ Log2 بواجهة panic وتضيف Log2WithPrec لمعالجة الأخطاء صراحةً. |
| الأخطاء وpanic | أصبحت فئات panic العددية تعرض أخطاء مرجعية من النوع error. تغلف أخطاء فك الترميز ErrUnmarshal مع الاحتفاظ بالسبب. حدّث تأكيدات النوع النصي ومقارنات رسائل الخطأ وتأكيدات النوع الخارجي. |
| ترميز nullable | تعني Valid=true مع Decimal غير مهيأ صفرًا صالحًا في JSON/XML/BSON. استخدم Valid=false للقيمة null. |
| التحليل وYAML | تُرفض العلامات المكررة غير الصالحة. يحافظ فك ترميز أرقام YAML على الأرقام الأصلية وقواعد القيم المفردة لدى المفكك بدل المرور عبر float64. |
| التمثيل | تحتفظ دالتا المثيل Max/Min بالمعامل الأول عند تساوي القيم. يختار `%g/%G` طريقة العرض بعد التقريب، بما في ذلك انتقال الحمل إلى الأس. راجع اللقطات التي تعتمد على المقياس أو النص. |

يبقى الحد الأدنى **Go 1.26.0+**. لا يتغير مسار الوحدة، ولا تُحذف أي واجهة API
مصدّرة من v0.7.0. لا يتغير تخطيط Binary، ولا تضمن الترميزات المضغوطة الاحتفاظ
بالمقياس أو حالة التهيئة. تحافظ أخطاء فك الترميز على حالة المستقبِل كاملةً، بما فيها NullDecimal.Valid.

راجع [دليل الترقية بالإنجليزية](https://github.com/exc-works/decimal/blob/v0.8.0/docs/numeric-contract-migration.md)
أو [بالصينية المبسطة](https://github.com/exc-works/decimal/blob/v0.8.0/docs/upgrade-v0.8.0.zh.md).

## صحة النتائج والواجهات الجديدة

- تقرّب MulWithPrec حاصل الضرب الدقيق مرة واحدة عند مقياس الإخراج المحدد؛ لا تستعيد زيادة مقياس ناتج سبق تقريبه الأرقام المفقودة.
- توفر Log2WithPrec تحديد مقياس الإخراج ومعالجة الأخطاء صراحةً.
- تُقرّب القسمة مباشرةً عند المقياس النهائي؛ تعطي `16.0 / 11` عند المقياس 0 مع HalfEven القيمة `1`. تحتفظ الأسس السالبة بالمقام الدقيق حتى التقريب النهائي.
- تستخدم الجذور مقارنات دقيقة لنقاط المنتصف بالأعداد الصحيحة وحدًا أعلى محسنًا للدرجات العالية. تثبت اللوغاريتمات والدوال الأسية صحة HalfEven بفترات مقربة إلى الخارج وحدود صريحة لباقي المتسلسلة.
- لا يغير فشل فك الترميز الحالة جزئيًا؛ يُفحص التجاوز قبل التفاف حساب المقياس، وترفض المسارات السريعة أوضاع التقريب غير الصالحة.

يحدد [العقد العددي](https://github.com/exc-works/decimal/blob/v0.8.0/docs/numeric-contract.md)
القواعد. تجمع CI بين شهادات مستقلة بأعداد نسبية دقيقة وفترات، و45 حالة يجب أن تنجح،
واختبارات fuzz محدودة للحساب والجذور، واختبارات race وتكامل BSON وmapstructure،
وفحوص صحة على amd64/386. تختبر هذه الفحوص النجاحات الموعودة وسلوك الفشل؛ وتظل
المدخلات العامة خاضعة لميزانيات الحساب الموثقة.

## الأداء

تتجنب استعلامات الأعداد الصحيحة نتائج القسمة غير المستخدمة، ويتجنب تحويلها إلى
الفاصلة العائمة إنشاء أعداد نسبية. تعيد التحويلات النسبية وتقريب الأرقام المعنوية
استخدام مخازن ذات ملكية مستقلة، ويستخدم التقريب ذو الإشارة تنفيذًا موحدًا.
تعيد حلقات اللوغاريتمات والدوال الأسية استخدام مساحة العمل وتستخدم اختزالًا محدودًا
للوسيط. لا تُضاف ذاكرة تخزين مؤقت عامة جديدة أو مساحة عمل مشتركة قابلة للتغيير.

تغييرات نموذجية في عدد تخصيصات الذاكرة من سلسلة التحسين الأخيرة على Go 1.26.6
وdarwin/arm64: استعلامات الأعداد الصحيحة 3 → 0 لكل عملية؛ Float64 لعدد صحيح
7 → 0؛ إنشاء BigRat صحيح ودقيق 10 → 2؛ Rescale السالب مع HalfEven 9 → 4.
المراجع الأساسية موثقة في [تقرير benchmark](https://github.com/exc-works/decimal/blob/v0.8.0/docs/allocation-benchmarks.md)؛
ولا تمثل مقارنةً موحدةً مع v0.7.0 أو ضمانًا لجميع المدخلات.
